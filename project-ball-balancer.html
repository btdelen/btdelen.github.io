STM32 PID Ball Balancer

C STM32 HAL PID Control Sharp IR

Overview

A single-axis ball balancing system demonstrating real-time PID control implementation on STM32 microcontroller. Features live UART telemetry for parameter tuning and system monitoring.

Key Features

  • ⚡
    Real-time PID Control

    Tuned Kp, Ki, Kd parameters for stable ball positioning

  • 📏
    Sharp IR Distance Sensor

    Analog distance measurement with noise filtering

  • 📊
    UART Telemetry

    Live data streaming for debugging and parameter tuning

  • 🔧
    Custom Hardware Integration

    Designed with optimized sensor mounting and precise actuation

Wiring Diagram

Component Pin STM32
Sharp IR VCC 5V
Sharp IR OUT PA0 (ADC)
Servo PWM PA1 (TIM2_CH2)
